# 12 · 应期与应验

08 册应期总注给出的是**单通道法则**（静待冲值、动待合值、化退忌值……）。本册讲更进一层的四件事：

> **多通道交叉定位（何时）→ 化出之支定事性（何事何性）→ 应验分层核对（应没应）→ 验卦复盘（断后校准）。**

断卦的功夫在断前，校准的功夫在断后——没有验卦闭环的应期法则只是口诀。

## 一、应期多通道交叉定位（何时）

单通道法则见 08·三·补。实务中**一个卦往往同时开通多条通道，通道交汇处即高置信应期**：

| 通道 | 法则（摘自 08 总注） | 本卦例 |
|---|---|---|
| 动待合值 | 动爻逢合神之日/月 | 世爻卯动 → 合神戌 → **戌月** |
| 化变值日 | 动爻应于变爻值日（化退亦逢值而应） | 卯化寅 → **寅日** |
| 用/世值日 | 主事爻本位值日 | 世爻卯 → **卯日** |
| 衰待当令 | 用神衰 → 当令之月（窗口期） | 亥水衰 → **亥子月** |
| 墓待冲 | 入墓 → 冲墓之月（防错位） | 卯入未墓 → **丑月**（丑土克水，财同转弱） |
| **破待填 → 局成** | 局中月破之支值令填实、所待之支临日建——三合成实，**备用管道接棒**（用神失令之月的回血强脉冲；局法见 06 册「局之进阶」） | 巳酉丑金局：**丑月**填实破支、**巳日**临值成局化金 → 生亥回血 |

**置信度分级：**

- **高置信**：≥2 通道指向同一时间窗 → 可明言窗口。
- **候选**：单通道 → 只作候选，标注前提条件。
- **辩证**：通道利好互相冲突（如冲墓利世、却克用神）→ 不取单一"好月份"，分层给出（见 08 走查⑧、SKILL 辨析 8）。

> 本卦例（占于未月辛卯日，事验于戌月戊寅、己卯两日）：世爻动而合神值**月**（戌）、变爻值**日**（寅）、世爻值**日**（卯）——三通道交汇，应期落点精确到两日之内。这是"多通道交叉"优于单通道背诵的直接例证。

## 二、化出之支的多重身份（何事、何性）

08 总注言"**化退神忌值、忌冲**"——化退之爻，其事多应在**变爻值日/冲日**兑现。但兑现的**是什么性质的事**，须并看化出之支的**三重身份**：

| 身份 | 看什么 | 主什么 |
|---|---|---|
| **气机** | 进神/退神 | 势的方向（进=增益前进，退=消退退缩） |
| **损益** | 回头生克 | 变爻对动爻本身的生克 |
| **落点** | 与用神/世爻的六合六冲 | 变化最终**绑定谁、成全谁** |

**⭐ "退而得合"**：化退主退，但化出之支若**六合用神（或世爻）**，则此"退"以"合"落地——主动退让反成全结合；应期仍取变爻值日，事性却是正面的和合。反之，化进而化出之支冲克用神，则是"进中有损"。**化进≠吉、化退≠凶，三重身份并看方能定性。**

> 本卦例：世爻卯化寅（退神），而寅**六合用神亥水**——应验于寅日（变爻值日，合法则），兑现的是关系确立（合象落点）。求测者一方主动放低赴约（退象气机），退而成其合。若机械套"化退=凶"，此卦全盘误读。

## 三、应验分层（应没应）

卦的结论是**一组条件**（合象已动、用神未当令、墓未冲开……），应验也必是**分层的**，不是成/败二值。方法三步：

1. **拆层**：把占事拆成递进层次。姻缘例：牵绊 → 关系确立 → 同住 → 亲密之实 → 全实/婚成。
2. **对条件**：每层对应卦象条件——条件已备=可应；条件含"待时"=待应。
3. **逐层核对**：应验时记录哪层已应、以何通道应。

| 层次 | 卦象条件 | 本卦例 |
|---|---|---|
| 牵绊不断 | 亥卯未虚合 + 变卦六合 + 日建根 | 持续在 |
| 关系确立 | 化出寅合用神亥（落点）+ 合神值月 | **已应**（寅日） |
| 同住 | 世爻被月建合住（卯戌合）+ 应临勾陈（安定久留） | **已应**（戌月） |
| 亲密之实 | 动爻爻辞"咸临"——咸者感也，以感相应 | **已应** |
| 全实 | 用神亥水**当令**（亥月方旺）+ 世爻未出未墓 | **待亥月**（占时明断"亥子月最佳窗口"） |

**原理**：分层应验是"缘分实而未至其时"这类分层结论的忠实映射。**占时把层与条件写清，验卦时才有得核对**——这也倒逼断卦输出分层化、条件化（见 08·四 输出规范），拒绝"一句吉凶了事"。

## 四、验卦复盘法（断后校准闭环）

1. **钉死事实**：事件公历日期 → 干支（年/月/日）；事实内容按层记录。
2. **逐象对应**：每条断语 → 对应通道（值/合/冲/填/当令/分层），列成对照表。
3. **证据分级**（⭐ 诚实是校准的前提）：
   - **强证据**：**事前**写下的断语（verdict、应期表）事后兑现。本卦例"最佳窗口在亥子月"写于占时未验之前，属事前断语。
   - **弱证据**：应验之后**补做**的对应解释（事后补释）。事后解读天然有弹性，只作参考、不得冒充验证。
4. **归档**：匿名版进 `examples/`（可附应验标注）；涉真实姓名/地点/隐私的记录进 `private/`（已被 `.gitignore` 排除，永不提交）。
